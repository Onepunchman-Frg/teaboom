# Ананасовый улун — страница товара

Карточка товара для чая "Ананасовый улун". 
Основной файл сайта — `index.html`, к которому подключены стили (`styles/styles.css`) и внешний JS/CSS-фреймворк tiny-slider.

## Структура страницы

- **Навигация-хлебные крошки**: В верхней части реализован путь навигации с текущей позицией на странице "Ананасовый улун".
- **Блок товара**:
  - Заголовок и название чая.
  - Карусель изображений товара с поддержкой миниатюр/превью (tiny-slider).
  - Описание и, возможно, дополнительные характеристики чая (в основном содержимое `<article class="card-block">`).

## Используемые технологии

- **HTML5** — семантическая разметка.
- **CSS3** — кастомные стили (подключены в `styles/styles.css`), адаптивность через meta viewport.
- **Google Fonts** — шрифт Open Sans.
- **tiny-slider** — библиотека для создания слайдера изображений (подключение через CDN).

## Быстрый старт

1. Клонируйте или скачайте репозиторий.
2. Убедитесь, что пути к изображениям и стилям указаны корректно.
3. Откройте `index.html` в браузере.

## Состав проекта

- `index.html` — основная HTML-страница, полностью на русском языке.
- `styles/styles.css` — все кастомные стили.
- `images/` — папка с изображениями товара (например, `card-1.jpg`).
- `fonts/` — паки с иконками.
- `js/` — скрипты.
